A tiny deterministic program (Node 22+ stdlib only) that writes one original one-line excuse — in the voice of a hardware wallet refusing to sign a transaction at 3 AM — to `/output/entry.txt`. Under 200 characters, one line, no title, no explanation. It self-checks the gate (1–200 characters, single line) before writing, and produces byte-identical output on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
